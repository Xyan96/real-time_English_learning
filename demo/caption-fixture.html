Fake Netflix-style rendered subtitle DOM

Load the unpacked extension, serve this folder over localhost, and the transcript overlay should appear after the first subtitle change.

Manual extension check

  1. Load this repository with Chrome Developer mode and Load unpacked.
  2. Wait for at least two subtitle changes. A Live Transcript overlay should appear in the lower-right corner.
  3. Open the extension popup. It should report collected transcript lines.
  4. Use Copy TXT or Download SRT from the popup and confirm the exported text includes the cycling subtitle lines.
  5. Use Clear Current Transcript. The overlay should disappear until the next subtitle change.
(() => { const overlay = document.querySelector('#rvt-overlay'); return { contentScriptLoaded: Boolean(window.__realtimeVideoTranscriberLoaded), overlayVisible: Boolean(overlay && !overlay.hidden), transcriptLines: Array.from(overlay?.querySelectorAll('.rvt-text') || []).map((node) => node.textContent) }; })()
